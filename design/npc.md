# NPC 功能解锁系统设计文档

> 版本：v1.0 | 日期：2026-06-19 | 作者：Codex + 用户协作

---

## 1. 系统定位

每个 NPC 都拥有独立的「功能解锁树」：好感达到指定阶段后，玩家提交指定材料与铜钱，永久解锁该 NPC 的专属功能。解锁后，部分 NPC 还提供每周一次的「帮办」服务（已在 `NPC_ACTIVE_SERVICE_DEFS` 中实现）。

本系统不替代现有的关系收益（折扣 / 配方 / 线索 / 委托解锁），而是在其之上增加一层「材料解锁 → 功能开放」的成长闭环。

### 与现有系统的关系

| 现有系统 | 本系统 | 关系 |
|----------|--------|------|
| `NPC_RELATIONSHIP_BENEFITS`（折扣/配方/线索/委托） | 功能解锁树 | 并行：关系收益自动触发，功能解锁需主动提交材料 |
| `NPC_ACTIVE_SERVICE_DEFS`（每周帮办） | 帮办服务 | 依赖：解锁 T1 后才开放帮办入口 |
| 心事件（`HeartEventDef`） | T3 / T4 功能 | 并行：心事件是叙事，功能解锁是 gameplay |
| 知己/伴侣/家庭系统 | T4 深度功能 | 依赖：必须先完成知己/伴侣关系绑定 |

## 2. 关系阶段阈值

| 阶段 | 好感值 | 标签 | 说明 |
|------|--------|------|------|
| 陌路 | 0 | recognize | 初见 |
| 相识 | >=250 | familiar | 开始有来往 |
| 相知 | >=1000 | friend | 彼此信任 |
| 挚友 | >=2000 | bestie | 深度信赖 |

可婚 NPC 在挚友之后可进入：约会 -> 求婚 -> 婚后 -> 知己/家庭。

不可婚 NPC 在挚友之后可进入「深交」（deep bond），表现为更高级的功能解锁和特殊对话线。

## 3. 解锁机制

### 3.1 核心规则

1. **门槛前置**：好感必须达到该阶段阈值，材料不足时按钮灰显并显示缺少的物品和数量。
2. **材料消耗**：解锁时一次性消耗材料，不可退还。
3. **永久生效**：解锁后功能永久可用，不随周目重置。
4. **逐级递进**：必须依次解锁 T1 -> T2 -> T3 -> T4，不可跳级。
5. **不可回退**：已解锁的功能不可取消或降级。

### 3.2 数据结构

```typescript
export interface NpcFunctionUnlockDef {
  id: string                          // 唯一标识，如 'xiao_man_T1_tool_repair'
  npcId: string                       // 所属 NPC
  tier: 'T1' | 'T2' | 'T3' | 'T4'   // 解锁档位
  requiredStage: RelationshipStage    // 所需关系阶段
  title: string                       // 功能名称
  summary: string                     // 功能描述
  materialCost: { itemId: string; quantity: number }[]
  costMoney: number                   // 铜钱消耗（0 = 无需铜钱）
  effectType: string                  // 功能类型标识（用于 store 读取）
  effectPayload?: Record<string, unknown>
}

// 存档字段（新增到 NpcState）
unlockedFunctionIds: string[]
```

### 3.3 解锁 UI 入口

在 NPC 详情页的「关系」tab 中新增「功能解锁」区块：

- 顶部显示当前已解锁档位进度条（T1 -> T2 -> T3 -> T4）
- 每个未解锁档位显示：所需好感阶段、材料清单、铜钱费用
- 材料充足时按钮高亮，不足时灰显并标注缺少物品
- 已解锁档位显示「已解锁」标记和功能简述
- 帮办服务入口在解锁 T1 后才可见

### 3.4 存档兼容

- 新字段 `unlockedFunctionIds: string[]` 写入 `NpcState`
- 旧档缺失时默认为空数组，不影响现有功能
- save 版本号不需变更（向后兼容）

### 3.5 经济约束

| 档位 | 铜钱参考范围 | 材料稀有度 | 设计意图 |
|------|-------------|-----------|---------|
| T1 | 300-800 | 基础材料（木材/竹子/草药/矿石） | 早期可触达，鼓励社交 |
| T2 | 800-2000 | 中级材料（铁锭/布料/丝线/加工品） | 中期目标，需要加工链 |
| T3 | 2000-4000 | 高级材料（金矿/黑曜石/灵芝/丝绸） | 后期奖励，需探索+积累 |
| T4 | 4000-6000 | 稀有材料（灵蚕丝/珍稀矿/特殊物品） | 终局内容，需深度投入 |

## 5. 仙灵解锁规则

仙灵（隐藏 NPC）使用独立的好感/缘分/结缘系统，不走固定村民的好感阶段。

### 5.1 仙灵列表

| 仙灵 | ID | 结缘物 | 结缘门槛 | 结缘石 | 显化日 |
|------|----|--------|---------|--------|--------|
| 龙灵 | long_ling | 龙鳞符 | 缘分>=1800 | 龙灵珠 | 春14 |
| 桃夭 | tao_yao | 花冠 | 缘分>=1800 | 永恒之花 | 春3 |
| 月兔 | yue_tu | 玉杵 | 缘分>=1800 | 月华仙丹 | 秋14 |
| 狐仙 | hu_xian | 狐火灯笼 | 缘分>=1800 | 狐仙灵珠 | 秋7 |
| 山翁 | shan_weng | 修道玉 | 缘分>=1800 | 仙人葫芦 | 冬1 |
| 归女 | gui_nv | 银丝戒 | 缘分>=1800 | 星光织机 | 冬21 |

### 5.2 仙灵功能解锁

仙灵的功能解锁通过「共鸣点」（resonancePoints）驱动：

| 档位 | 条件 | 功能类型 | 示例（龙灵） |
|------|------|---------|-------------|
| 能力1 | 缘分>=500 | 被动能力 | 龙泽：灌溉效率+15% |
| 能力2 | 缘分>=1200 | 被动能力 | 唤雨：下雨概率+15% |
| 能力3 | 缘分>=2000 | 被动能力 | 龙瞳：传说鱼捕获率+20% |
| 求缘 | 缘分>=1800+结缘物 | 解锁求缘对话线 | - |
| 结缘 | 缘分>=2500+结缘石 | 解锁结缘羁绊 | 每日被动效果 |

### 5.3 与固定村民的区别

- 仙灵使用 useHiddenNpcStore，不走 useNpcStore 的好感阶段
- 仙灵的「材料」是专属结缘物品，不是通用材料
- 仙灵全局只能结缘 1 位，解缘后好感上限降至 1000
- 仙灵的功能解锁已在 abilities 数组中定义，本系统不重复覆盖

## 6. 随机来客解锁规则

随机来客使用模板驱动的好感系统，好感上限 100。

### 6.1 随机来客功能解锁

随机来客的功能解锁通过「关系事件」驱动，而非材料提交：

| 关系阶段 | 好感阈值 | 解锁内容 |
|----------|---------|---------|
| 过客->旧识 | >=45 | 小订单系统开放，接收日常委托 |
| 旧识->长住 | >=70 | 长住故事线开放，推进 3 阶段关系事件 |
| 长住->恋人 | >=85 | 短期恋爱/家人线开放（需方向匹配） |
| 长住->家人 | >=75+family_impression | 家族委托、见面、企业开放 |

### 6.2 与固定村民的区别

- 随机来客使用 useNpcStore.getRandomNpcBoard()，不走固定 NPC 的关系收益表
- 随机来客的好感上限为 100（固定村民无上限）
- 随机来客的功能解锁是叙事驱动，不是材料驱动
- 随机来客的模板定义在 RANDOM_NPC_TEMPLATES 中

### 6.3 随机来客路线

| 路线 | ID | 特色功能 |
|------|----|---------|
| 商业 | business | 商品交易、商路信息、物资交换 |
| 友情 | friendship | 日常互动、邻里互助、村中记忆 |
| 看护 | caregiving | 动物护理、药材采集、养生建议 |
| 手艺 | craft | 工艺制作、材料加工、工具改良 |
